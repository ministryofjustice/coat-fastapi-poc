This folder records significant architecture decisions for coat-api, including the context and reasoning behind them.

## Adding a new ADR

1. Copy the structure of an existing ADR.
2. Name the file with the next number and a short title, e.g. `0002-short-title.md`.
3. Include these sections: Status, Context, Decision, Consequences.
4. Add it to the index table above.
